# M2 可靠聊天 Alpha：验收记录

日期：2026-09-29。环境：模拟器 `Medium_Phone`（Android 15，x86_64，开发构建）+ WSL 中的 Memoh 开发栈（`dev` 版本，含 PR #1405，模型已配置）。

## 退出标准与证据

| 标准 | 结果 | 证据 |
| --- | --- | --- |
| 发送 → 后台 → 杀进程 → 服务端完成 → 冷启动，结果完整 | 通过 | 长回复流式中强杀，冷启动后回复完整至第 10 项；服务端历史中该请求只有一次（`af9f66e`） |
| run/turn 不重复 | 通过 | 同上；重发复用 invocation ID，`duplicate:true` 视为已接受；新会话两阶段创建，断网 + 杀进程后恢复仍只创建一次（`f35ec99`） |
| 冷启动回到原阅读位置 | 通过 | 列表中部位置强杀后冷启动，截图一致；重装 APK 后同样恢复（`a33b8b1`） |
| ACK 丢失 | 通过（单测 + 真实服务端查询） | 进程在发送中被杀 → 条目标为 `unconfirmed`；按服务端已证实的能力查询 / 同 ID 重发 / 请用户确认。查询客户端对开发栈四种结果（found / not found / session gone / 路由缺失）均验证 |
| 断网 | 通过 | 飞行模式下历史从本地打开；状态条分别显示“未连接”和“1 条消息将在连接后发送”；恢复网络后自动发出并收到回复 |
| 跨 Team 隔离 | 通过（单测），真机不可测 | 所有表按 deployment + account + team 键隔离，退出登录清除对应数据（`stores.test.ts`）。OSS 服务端只有一个固定 Team，无法在真实部署上验证多 Team |

## 已知限制

- 审批 / 回答问题（CH-10）：开发栈模型不调用工具，只按源码契约、单测和开发预览页验证，未在真实工具调用上验证。
- 性能：P0.4 数值来自模拟器软件渲染，真机 2206123SC 复测前不作为达标结论。
- 真机需重新构建（新增 `expo-crypto`、`expo-clipboard`）。
- release 构建禁止明文 `http://`，自托管常见的局域网 HTTP 地址需在公开发布前决定处理方式。
