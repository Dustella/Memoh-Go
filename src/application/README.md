# 应用服务

预留位置，无业务实现。依赖 core 的类型与 ports，由 bootstrap 注入具体适配器，不 import React、Expo 或 data 的具体实现。

- commands：发送、控制、上传、设置变更等用例。不同操作分别规定离线与幂等策略，不默认所有 mutation 都能自动排队。
- queries：提供带 scope、新鲜度和细粒度订阅的读模型；以稳定实体 ID 定位，避免全局刷新。
- sync：活动 scope 唯一协调器，编排鉴权、补差、快照、实时订阅、Outbox 核对、退避与生命周期提示。

持久事务提交后发布对应读模型；未持久实时尾部单独标识，不能提前推进持久 cursor。页面是否挂载不决定服务端任务生死。订阅释放只调整客户端资源使用。
