# 平台适配

预留位置，Android 优先，同时保留 iOS 实现路径。

- lifecycle：App 前后台、网络提示、系统恢复入口；不承担同步决策。
- credentials：安全凭据存储与清理；不保存到普通配置。
- files：系统文件选择、持久附件目录、下载和分享。
- notifications：注册与通知入口；核验 scope 后请求同步，不能直接改 Run。
- diagnostics：脱敏日志、构建信息和恢复耗时；不采集 token/私有正文。

适配 core/ports 所需的最小接口，必要时增加平台专属文件。只有通知等能力真正实施时才选择依赖，不创建假定永远在后台运行的服务。
